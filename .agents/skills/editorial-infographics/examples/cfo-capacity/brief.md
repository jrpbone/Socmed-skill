# Worked example — CFO of AI capacity

## Source

- Topic: controlling AI capacity before granting autonomy
- Audience: operators and company leaders using agents
- Platform: Pinterest, 1000 × 1500

## Evidence pack

| Claim or asset | Status | Source | Limitation |
|---|---|---|---|
| Capacity should be budgeted before autonomous execution | inference | internal operating model | illustrative operating principle, not a universal benchmark |
| The visual contains no performance statistic | verified | final copy | avoids invented savings claims |

## Five-second takeaway

After seeing this image for five seconds, the viewer should understand that autonomous execution must pass through a budget threshold.

## Visual decision

- Primary job: explain
- Information topology: multiple possible actions narrow into a budget decision
- Layout family: convergence
- Why this structure fits: the agent may have many possible actions, but only approved capacity should cross the threshold
- Dominant visual element: thin cyan paths converging into one gate, followed by a single black execution line
- Canvas: warm paper
- Production method: deterministic vector and type

## Copy

- Title: `La autonomía empieza en un límite.`
- Labels: `presupuesto`, `ejecución`, `evidencia`
- Source line: `DÍA UNO · CFO de capacidad IA`
