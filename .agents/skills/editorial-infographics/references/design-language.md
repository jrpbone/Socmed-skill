# Editorial design language

## Goal

Make the piece feel composed around a specific idea. The viewer should notice the relationship being explained before noticing the visual effect.

## Core grammar

### Canvas

- Prefer quiet paper-like or cool neutral backgrounds.
- Use negative space as part of the hierarchy, not as empty leftover area.
- Keep one visual center of gravity; asymmetry is welcome when balanced.

### Typography

- Use one sans-serif family with no more than two weights, plus an optional mono label style.
- Let scale create hierarchy; avoid five competing text styles.
- Titles should state the insight, not name the topic.
- Body copy is supporting evidence, not a miniature article.

### Geometry

- One dominant spatial metaphor per image.
- Hairline connectors, direct labels, and small indices are preferred to floating cards.
- Shapes should encode containment, convergence, hierarchy, sequence, magnitude, or overlap.
- Soft blur or gradient may indicate depth, influence, or a boundary. It must not exist only to look futuristic.

### Color

- Start with ink + paper + one accent.
- Add a second accent only when it encodes a distinct category.
- Keep saturation localized to the insight.
- Do not use the default purple-blue AI gradient.

### Texture and humanity

- Use real screenshots, photographed objects, a small human silhouette, handwriting, or source artifacts when they add scale or credibility.
- Avoid decorative robots, glowing brains, circuit heads, holograms, and stock “AI” symbolism.

## Anti-patterns

- headline plus three rounded cards;
- dark dashboard background for every topic;
- glassmorphism without an interface reason;
- icon per bullet as decoration;
- fake product UI;
- data with no source or denominator;
- the same grid repeated with different copy;
- every element centered;
- excessive glow, pill badges, all caps, and tiny footer text;
- a visual that becomes meaningless when the headline is removed.

## Reference use

When the user supplies design references:

1. Identify hierarchy, rhythm, topology, density, contrast, and material treatment.
2. Write those traits as a design brief.
3. Do not copy exact copy, distinctive artwork, or the original composition point-for-point.
4. Create a new layout that serves the user's content and brand.
