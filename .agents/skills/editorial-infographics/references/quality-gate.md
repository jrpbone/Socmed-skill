# Anti-slop quality gate

Score each criterion from 0 to 2.

| Criterion | 0 | 1 | 2 |
|---|---|---|---|
| Five-second takeaway | unclear | topic is clear | insight is unmistakable |
| Visual job | decorative | partly useful | explains, proves, compares, maps, or humanizes |
| Evidence integrity | invented or absent | incomplete context | verified, sourced, and honestly framed |
| Topology fit | arbitrary template | acceptable | relationship and layout reinforce each other |
| Editorial hierarchy | competing elements | readable | deliberate focal point and rhythm |
| Human specificity | generic AI motifs | some specificity | unmistakably tied to the real subject or brand |
| Mobile legibility | fails thumbnail | mostly readable | works at feed thumbnail size |
| Batch originality | repeated template | minor variation | distinct composition within a coherent system |

## Passing rule

- minimum total: **13 / 16**;
- no zero in `Evidence integrity`, `Visual job`, or `Mobile legibility`;
- if the piece uses a factual number, quote, or UI claim, the source must be present in the receipt;
- if another asset in the batch shares the same skeleton, redesign one of them.

## Thumbnail test

View the whole batch at approximately 240 px wide per asset.

Check:

1. Can each asset be distinguished without reading the footer?
2. Is the dominant relationship visible?
3. Is the smallest essential label readable?
4. Do two pieces look like the same template with new words?
5. Does one accent color guide attention instead of tinting everything?

## Red-team questions

- Could this graphic belong to any AI company?
- Would removing the headline reveal useful information?
- Is the most visually prominent element also the most important idea?
- Did we use a card because the content required a container, or because cards are easy?
- Is any gradient explaining depth, influence, or containment?
- Would a screenshot, chart, or diagram be more truthful than an illustration?
